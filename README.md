# Python for Computational Materials & Machine Learning

A hands-on Python tutorial series covering scientific computing, numerical methods, data analysis, machine learning, and deep learning.

The tutorials are designed for engineering, materials science, and related students who want to develop practical computational skills using Python.

---

## 🚀 Tutorials

All tutorials are provided as Jupyter/IPython notebooks and can be run directly in **Google Colab**.

## 🛠️ Python Libraries

The tutorials use the scientific Python ecosystem, including:

- **NumPy** — numerical arrays and linear algebra
- **Pandas** — data analysis
- **Matplotlib** — scientific visualization
- **Seaborn** — statistical visualization
- **SciPy** — scientific and numerical computing
- **scikit-learn** — classical machine learning
- **PyTorch** — deep learning

Additional libraries that may be useful for computational materials work include:

- **pymatgen**
- **matminer**
- **ASE**
- **pathlib**
- **os**
